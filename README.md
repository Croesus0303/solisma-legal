# Tarotum Legal Documents

Legal documents and support pages for the Tarotum iOS app.

## Overview

This repository contains all the legal documents required for App Store submission, including:

- **Privacy Policy** - Data collection and handling practices
- **Terms of Service** - Usage rules, subscription terms, and legal agreements
- **Support Page** - Help center with FAQs and contact information
- **Entertainment Disclaimer** - Important information about tarot readings

All documents are available in **English** and **Turkish**.

## Enabling GitHub Pages

1. Go to repository **Settings**
2. Navigate to **Pages** section
3. Under "Source", select **Deploy from a branch**
4. Select **main** branch and **/ (root)** folder
5. Click **Save**

The site will be available at `https://croesus0303.github.io/tarotum-legal/` within a few minutes.

## Customization

Before publishing, update the following placeholders:

- `tarotumusa@hotmail.com` - Replace with your actual support email
- Developer/company name if needed in legal documents
- Any pricing information if it changes
